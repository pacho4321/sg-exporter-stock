# Singapore Exporter Stock

Simple showcase page for cars sourced in Singapore that are available for other exporters.

## Live page

Once GitHub Pages is turned on, the site will be at:
https://pacho4321.github.io/sg-exporter-stock/

To turn it on:
1. Go to the repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / root
4. Save

## How to add or change a car

1. Open `index.html`
2. Find the `const cars = [` list near the bottom
3. Copy one of the existing blocks and edit the details
4. Commit the change

The page updates automatically when you save.
